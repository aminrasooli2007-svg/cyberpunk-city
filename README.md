## ✨ Features

- 🌌 Futuristic cyberpunk atmosphere
- 🌙 Glowing moon and animated starfield
- 🏙️ Layered neon skyscrapers
- 💜 Cyan, purple, and pink neon lighting
- 🌧️ Pure CSS animated rain
- 💡 Flickering neon signs and building windows
- 📱 Responsive layout for mobile and desktop
- ♿ Reduced-motion accessibility support
- ⚡ Lightweight and framework-free

## 🛠️ Built With

- HTML5
- CSS3
- CSS Animations and Keyframes
- CSS Gradients and Visual Effects
- Responsive Media Queries

## 🎨 Design Concept

NEON CITY explores a futuristic urban environment through layered architecture, atmospheric gradients, glowing signage, and subtle motion effects.

The entire visual experience is created with HTML and CSS, demonstrating how modern CSS can produce immersive scenes without JavaScript.
